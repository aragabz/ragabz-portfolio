## The Modern Stack

### Frontend: React + TypeScript + Vite

React remains the dominant choice for building user interfaces, and when combined with TypeScript and Vite, it becomes even more powerful.

```typescript
// Modern React component with TypeScript
import { useState, useEffect } from 'react';

interface User {
  id: number;
  name: string;
  email: string;
}

export function UserProfile({ userId }: { userId: number }) {
  const [user, setUser] = useState<User | null>(null);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    fetch(`/api/users/${userId}`)
      .then(res => res.json())
      .then(data => {
        setUser(data);
        setLoading(false);
      });
  }, [userId]);

  if (loading) return <div>Loading...</div>;
  if (!user) return <div>User not found</div>;

  return (
    <div>
      <h1>{user.name}</h1>
      <p>{user.email}</p>
    </div>
  );
}
```

### Backend: Node.js + Express/Fastify

The backend ecosystem has matured with excellent frameworks:

```javascript
// Modern Express API with TypeScript
import express from 'express';
import type { Request, Response } from 'express';

const app = express();

app.get('/api/users/:id', async (req: Request, res: Response) => {
  try {
    const user = await db.users.findById(req.params.id);
    
    if (!user) {
      return res.status(404).json({ error: 'User not found' });
    }
    
    res.json(user);
  } catch (error) {
    res.status(500).json({ error: 'Internal server error' });
  }
});
```

## Architecture Decisions

### 1. API Design: REST vs GraphQL vs tRPC

Each approach has its strengths:

<Callout variant="note">
Your choice of API style is a trade-off. Start with REST for public-facing APIs, reach for tRPC when you control both ends, and use GraphQL when query flexibility outweighs complexity.
</Callout>

- **REST**: Simple, widely supported, great for public APIs
- **GraphQL**: Flexible querying, reduces over-fetching
- **tRPC**: End-to-end type safety, perfect for monorepos

### 2. State Management

Modern options include:
- **Zustand**: Lightweight and simple
- **TanStack Query**: Perfect for server state
- **Jotai**: Atomic state management

```typescript
// Zustand example
import create from 'zustand';

interface Store {
  count: number;
  increment: () => void;
}

const useStore = create<Store>((set) => ({
  count: 0,
  increment: () => set((state) => ({ count: state.count + 1 })),
}));
```

### 3. Database Choices

**PostgreSQL** remains the gold standard for relational data:
- ACID compliance
- Rich feature set
- Excellent performance
- Strong ecosystem

**MongoDB** for flexible document storage:
- Schema flexibility
- Horizontal scaling
- Rich query language

## Security Best Practices

<Callout variant="warning">
Security is a property of the whole system, not a checklist. Validate every input, never log secrets, and keep dependencies patched with automated tooling like Dependabot.
</Callout>

1. **Authentication**: Use established solutions (Auth0, Clerk, NextAuth)
2. **Authorization**: Implement role-based access control (RBAC)
3. **Input Validation**: Validate all user inputs
4. **HTTPS**: Always use secure connections
5. **Environment Variables**: Never commit secrets
