Extract your design system into a Gradle component library so it lives in one place and spreads everywhere.

<Callout variant="tip" title="What you'll learn">
- How to structure a `compose-ui-lib` subproject
- Publishing themed `Color`, `Typography`, and `Shape` to consuming apps
- Dark‑mode switching without rebuilding the host app
</Callout>

### Library module layout

```text
compose‑ui‑lib/
├─ src/
│  ├─ commonMain/
│  │  ├─ kotlin/
│  │  │  ├─ composeUi/       # Compose UI code (no Android resources)
│  │  │  └─ theme/           # Color, Typography, Shape, modifiers
│  │  └─ composeResources/   # Optional: Compose Multiplatform resources (images, vector icons, fonts)
│  ├─ androidMain/           # Android‑specific resources (drawables, styles)
│  └─ iosMain/               # iOS bridge (if targeting CMP)
```

### Core theme skeleton (commonMain)

```kotlin
// Color.kt
val LightColorPalette = lightColorScheme(
    primary = Color(0xFF6750A4),
    secondary = Color(0xFFFFC107),
    surface = Color(0xFFFFFFFF),
    background = Color(0xFFF5F5F5),
    onPrimary = Color.White,
    onSurface = Color.Black
)

val DarkColorPalette = darkColorScheme(
    primary = Color(0xFFBB86FC),
    secondary = Color(0xFFFFC107),
    surface = Color(0xFF212121),
    background = Color(0xFF121212),
    onPrimary = Color.Black,
    onSurface = Color.White
)

// Typography.kt
val Display1 = TextStyle(
    fontFamily = FontFamily.Default,
    fontWeight = FontWeight.W300,
    fontSize = 57.sp,
    lineHeight = 64.sp
)

// Shape.kt
val Rounded = RoundedCornerShape(16.dp)

// Theme.kt — composable that consuming apps call once at the root
@Composable
fun UiTheme(
    darkTheme: Boolean = isSystemInDarkTheme(),
    content: @Composable () -> Unit
) {
    MaterialTheme(
        colorScheme = if (darkTheme) DarkColorPalette else LightColorPalette,
        typography = Typography(displayLarge = Display1 /* …other text styles */),
        shapes = Shapes(medium = Rounded),
        content = content
    )
}
```

### Consuming the library in a host app

```kotlin
// androidApp — root composable
@Composable
fun App() {
    // CALL THIS ONCE, at the top of your Composition.
    // Don't nest another MaterialTheme inside — it would override the library theme.
    UiTheme { // default dark/light auto‑detection
        /* …your app screens… */
    }
}
```

Because `UiTheme` lives in the library, **any change to the color palette or typography propagates** to every app as soon as it bumps the dependency to the newly published version — no copy‑pasting theme code between projects.

### Dark‑mode handling without rebuild

```kotlin
// Host app: drive darkTheme from a user setting instead of only the system flag
@Composable
fun App(settings: SettingsRepository) {
    val themePref by settings.theme.collectAsStateWithLifecycle(initialValue = ThemePref.System)
    val dark = when (themePref) {
        ThemePref.Dark -> true
        ThemePref.Light -> false
        ThemePref.System -> isSystemInDarkTheme()
    }
    UiTheme(darkTheme = dark) { /* …your app screens… */ }
}

// Toggling the preference recomposes UiTheme with the other color scheme,
// so the UI refreshes instantly — no rebuild or Activity restart needed.
```

### Publishing the library to Maven Central

1. **Keep credentials and the signing key out of VCS** — put them in `~/.gradle/gradle.properties` locally, or as `ORG_GRADLE_PROJECT_*` environment variables in CI:
   ```properties
   mavenCentralUsername=<Central Portal token username>
   mavenCentralPassword=<Central Portal token password>
   signingInMemoryKey=<ASCII-armored GPG private key>
   signingInMemoryKeyPassword=<key password>
   ```
2. **Apply a publish plugin** in the library module’s `build.gradle.kts` (the community `com.vanniktech.maven.publish` plugin handles Central Portal uploads and signing):
   ```kotlin
   plugins {
       id("com.vanniktech.maven.publish") version "0.37.0"
   }
   ```
3. **Configure coordinates and publish** with `./gradlew publishToMavenCentral`:
   ```kotlin
   mavenPublishing {
       publishToMavenCentral()
       signAllPublications()
       coordinates("com.example", "compose-ui-lib", "0.1.0")
   }
   ```
4. **Consume from any project**:
   ```kotlin
   dependencies {
       implementation("com.example:compose-ui-lib:0.1.0")
   }
   ```

### Checklist for library authors

- [ ] All UI kits use **`MaterialTheme`** props (colors/typography) rather than hard‑coded `Color(0xFF…)`.
- [ ] `UiTheme` composable is **`@Composable`** and lives in `commonMain` — no Android resources inside the shared module.
- [ ] **Semantic naming**: `SecondaryColor`, `BodyText1`, `CardShape` — avoids collisions when multiple libraries are used together.
- [ ] **Test across versions**: publish a `0.1.0` → consume in a sample app, change the library version to `0.2.0` in the sample’s `build.gradle.kts`, sync, and verify the UI updates without a clean/rebuild of the host’s source set.
